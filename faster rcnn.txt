1. EXECUTIVE SUMMARY & EVOLUTION
--------------------------------------------------------------------------------
Faster R-CNN (Ren et al., NIPS 2015) is a seminal two-stage deep learning 
architecture for object detection. It eliminated the computational bottleneck of 
earlier detectors (R-CNN and Fast R-CNN) by introducing a Region Proposal 
Network (RPN) that reuses backbone feature maps, allowing proposal generation to 
run entirely on the GPU.

Evolutionary Comparison:
--------------------------------------------------------------------------------
Architecture   Proposal Method     Feature Extract   Inference Time  Training
--------------------------------------------------------------------------------
R-CNN (2014)   Selective Search    2,000 passes/img  ~49.0 seconds   Multi-stage
Fast R-CNN     Selective Search    1 pass/img        ~2.0 seconds    Single stage
Faster R-CNN   RPN (Neural Net)    1 pass/img        ~0.05-0.2s      End-to-End
--------------------------------------------------------------------------------

2. CORE COMPONENTS & PIPELINE
--------------------------------------------------------------------------------
Faster R-CNN operates in four distinct stages:

A. Backbone Feature Extractor
   - Input: Raw image (e.g., [3, H, W]).
   - Backbone Networks: VGG-16, ResNet-50/101, or Feature Pyramid Networks (FPN).
   - Output: Feature map reduced by stride S (e.g., [C, H/16, W/16]).

B. Region Proposal Network (RPN)
   - Slides a 3x3 conv filter over the backbone feature map.
   - At each sliding location, evaluates k predefined Anchor Boxes 
     (typically 3 scales x 3 aspect ratios = 9 anchors).
   - Outputs two parallel heads per anchor:
     1. Objectness Score (cls): Binary classification (Object vs. Background).
     2. Box Regression (reg): Offsets (dx, dy, dw, dh) relative to anchor.
   - Applies Non-Maximum Suppression (NMS) to eliminate duplicate overlapping 
     proposals (typically retains top 1,000–2,000 proposals).

C. RoI Pooling / RoI Align
   - Extracts feature regions corresponding to RPN proposals.
   - RoI Pooling uses max-pooling to map variable-sized proposal features into 
     a fixed-size grid (e.g., 7x7).
   - RoI Align (introduced in Mask R-CNN) replaces quantized pooling with 
     bilinear interpolation, avoiding misalignments caused by rounding.

D. Region-Based CNN Head (Classifier & Regressor)
   - Fully connected layers process fixed 7x7 spatial feature maps.
   - Final Outputs:
     1. Multi-class Softmax: Probabilities across N classes + 1 background.
     2. Class-specific Bounding Box Regression: Final refined box coordinates.

3. LOSS FUNCTIONS
--------------------------------------------------------------------------------
Faster R-CNN is trained end-to-end using a combined multi-task loss:

   L_total = L_rpn + L_cls_detector

Where:
- L_rpn = L_cls(RPN) + lambda * L_reg(RPN)
- L_cls_detector = L_cls(Detector) + lambda * L_reg(Detector)

1. Binary Cross-Entropy Loss (L_cls) for RPN objectness.
2. Cross-Entropy Loss (L_cls) for final multi-class identification.
3. Smooth L1 Loss (L_reg) for bounding box coordinates regression:
   
   Smooth_L1(x) = { 0.5 * x^2          if |x| < 1
                  { |x| - 0.5          otherwise

4. PYTORCH CODE IMPLEMENTATION EXAMPLE
--------------------------------------------------------------------------------
Below is a complete script demonstrating how to instantiate a pre-trained 
Faster R-CNN model with a ResNet-50-FPN backbone in PyTorch for inference:

```python
import torch
import torchvision
from torchvision.models.detection import FasterRCNN_ResNet50_FPN_Weights
from PIL import Image
import torchvision.transforms as T

# 1. Load Pre-trained Faster R-CNN Model
weights = FasterRCNN_ResNet50_FPN_Weights.DEFAULT
model = torchvision.models.detection.fasterrcnn_resnet50_fpn(weights=weights)
model.eval()

# 2. Image Preprocessing
transform = T.Compose([
    T.ToTensor()
])

def detect_objects(image_path, score_threshold=0.8):
    image = Image.open(image_path).convert("RGB")
    img_tensor = transform(image).unsqueeze(0)  # Add batch dimension
    
    with torch.no_grad():
        predictions = model(img_tensor)[0]
        
    boxes = predictions['boxes']
    labels = predictions['labels']
    scores = predictions['scores']
    
    # Filter predictions by confidence threshold
    keep = scores >= score_threshold
    filtered_boxes = boxes[keep]
    filtered_labels = labels[keep]
