                           YOLOv8 OVERVIEW & REFERENCE

1. WHAT IS YOLOV8?
------------------
YOLOv8 (You Only Look Once, Version 8) is a state-of-the-art computer vision model
developed by Ultralytics, released in January 2023. It is designed for real-time
object detection, instance segmentation, pose estimation, oriented bounding box (OBB)
detection, and image classification.

2. KEY ARCHITECTURAL FEATURES
-----------------------------
- Anchor-Free Detection:
  Unlike earlier YOLO versions that used pre-defined anchor boxes, YOLOv8 directly
  predicts the center of an object and its bounding box offsets. This reduces the
  number of hyperparameters and simplifies box prediction.

- Decoupled Head:
  YOLOv8 separates classification and bounding box regression into distinct branches.
  This decoupling improves accuracy and accelerates training convergence.

- C2f Building Block:
  Replaces the C3 module used in YOLOv5 with the C2f (Cross Stage Partial with 2
  convolutions) module, improving gradient flow while keeping the model lightweight.

- Mosaic Augmentation:
  Combines four training images into one to help the model learn objects at various
  scales and contexts (disabled during the final epochs of training to improve precision).

3. YOLOV8 MODEL VARIANTS
------------------------
YOLOv8 comes in five model scale variants to balance speed and accuracy:

  Name       Parameters (M)    GFLOPs    Ideal Use Case
  ----------------------------------------------------------------------
  yolov8n    3.2              8.7       Edge devices, mobile, microcontrollers
  yolov8s    11.2             28.6      Embedded systems with light GPU
  yolov8m    25.9             78.9      Balanced real-time application
  yolov8l    43.7             165.2     High accuracy on dedicated GPUs
  yolov8x    68.2             257.8     Maximum precision requirements

4. SUPPORTED COMPUTER VISION TASKS
----------------------------------
- Object Detection (Detect objects with bounding boxes)
- Instance Segmentation (Detect objects and outline their exact boundaries)
- Pose Estimation / Keypoint Detection (Identify body joints and poses)
- Image Classification (Categorize entire images)
- Oriented Bounding Box / OBB (Detect rotated objects, e.g., aerial images)

5. QUICK START CODE (PYTHON)
----------------------------
# Step 1: Install Ultralytics
# pip install ultralytics

from ultralytics import YOLO

# Load a pretrained model (e.g., YOLOv8 Nano)
model = YOLO('yolov8n.pt')

# Train the model on custom data
# model.train(data='data.yaml', epochs=100, imgsz=640)

# Run inference on an image
results = model('image.jpg')

# Display results
results[0].show()

6. PROS AND CONS
----------------
Pros:
- Fast inference speed suitable for real-time video processing.
- Multi-task support within a single framework.
- Easy-to-use Python API and CLI provided by Ultralytics.

Cons:
- Higher computational requirement for larger variants (yolov8l, yolov8x).
- AGPL-3.0 license requires open-sourcing commercial products unless an
  enterprise license is purchased.
