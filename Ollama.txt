3. ESSENTIAL OLLAMA COMMANDS
-------------------------------------------------------------------
• Run / Download & Chat:
  ollama run llama3

• Download Model without Running:
  ollama pull mistral

• List Installed Models:
  ollama list

• Show Model Info & Architecture:
  ollama show llama3

• Remove / Delete Model:
  ollama rm mistral

• Check Running Models:
  ollama ps


4. CUSTOM MODEL SETUP (MODELFILE EXAMPLE)
-------------------------------------------------------------------
To customize system prompts or parameters, create a file named 'Modelfile':

  FROM llama3
  PARAMETER temperature 0.7
  SYSTEM """You are an expert software architect providing concise code advice."""

Then create the custom model using:
  ollama create my-assistant -f ./Modelfile
  ollama run my-assistant
