1. INTRODUCTION TO NETWORKING
-----------------------------
Computer networking refers to the interconnected discipline of computing devices 
that can exchange data and share resources with each other. These networked 
devices use a system of rules, called communications protocols, to transmit 
information over physical or wireless technologies.

Networks are built with a mix of computer hardware (such as routers, switches, 
access points, and cables) and software (such as operating systems, firewalls, 
and applications). Today, networking forms the bedrock of modern communication, 
powering everything from the global Internet to internal corporate environments 
and smart home systems.


2. TYPES OF NETWORKS
--------------------
Networks are generally categorized based on their geographic scale and operational scope:

* Personal Area Network (PAN): 
  The smallest network type, centered around a single person in a single location. 
  An example is a Bluetooth connection between a smartphone and wireless headphones.

* Local Area Network (LAN): 
  Connects computers and devices within a limited geographical area, such as a 
  home, school, office building, or laboratory. LANs typically offer high data-transfer 
  rates and utilize Ethernet cables or Wi-Fi (WLAN).

* Metropolitan Area Network (MAN): 
  Covers a larger geographic area than a LAN but smaller than a WAN—typically a 
  town or a city. They are often owned and operated by a single consortium or a 
  town council (e.g., a city-wide public Wi-Fi network or cable TV network).

* Wide Area Network (WAN): 
  Connects computers across large physical distances. This allows computers and 
  smaller networks in one location to communicate with computers and networks in 
  other locations. The Internet is the largest and most well-known example of a WAN.

* Virtual Private Network (VPN): 
  By extending a private network across a public network, a VPN allows users to 
  send and receive data securely as if their computing devices were directly 
  connected to the private network.


3. NETWORK TOPOLOGIES
---------------------
A network topology defines the structural layout of a network. It can be viewed 
in two ways: physical topology (the actual layout of wires and cables) and logical 
topology (how data actually flows through the network).

* Star Topology: 
  All devices are connected to a central hub or switch. If a single device's cable 
  fails, only that device is disconnected. However, if the central hub fails, the 
  entire network goes down. This is the most common layout in modern LANs.

* Bus Topology: 
  Devices are connected to a single central cable, called the "bus" or "backbone". 
  It is simple and cheap to implement, but if the main cable breaks, the entire 
  network splits or fails.

* Ring Topology: 
  Devices are connected in a circular loop. Data travels in one direction around 
  the ring. If one device breaks, it can disrupt the entire network, although dual 
  rings can provide redundancy.

* Mesh Topology: 
  Every device is connected to multiple other devices. A full mesh means every single 
  node is connected to every other node. It offers extremely high redundancy and 
  fault tolerance but is costly and complex to install.


4. NETWORK MODELS (OSI VS. TCP/IP)
----------------------------------
To standardize how different systems communicate, conceptual models are used.

THE OSI MODEL (Open Systems Interconnection)
The OSI model divides network architecture into 7 distinct layers:
7. Application Layer: The human-computer interaction layer where applications 
   access network services (e.g., HTTP, FTP, SMTP).
6. Presentation Layer: Ensures that data is in a usable format and is where data 
   encryption and compression take place.
5. Session Layer: Maintains connections and is responsible for controlling ports 
   and sessions.
4. Transport Layer: Transmits data using protocols like TCP and UDP, handling 
   flow control and error checking.
3. Network Layer: Decides which physical path the data will take. It handles IP 
   addressing and routing.
2. Data Link Layer: Defines the format of data on the network. It deals with MAC 
   addresses and frames.
1. Physical Layer: The physical infrastructure of the network, converting digital 
   bits into electrical, radio, or optical signals (cables, hubs, etc.).

THE TCP/IP MODEL
The TCP/IP model is the practical suite of protocols used by the modern Internet. 
It consolidates the OSI model into 4 main layers:
1. Application Layer (Combines OSI Layers 5, 6, 7)
2. Transport Layer (Maps to OSI Layer 4)
3. Internet Layer (Maps to OSI Layer 3)
4. Network Access Layer (Combines OSI Layers 1, 2)


5. KEY NETWORKING PROTOCOLS
---------------------------
Protocols are formalized rules governing how data is formatted, transmitted, 
and received.

* IP (Internet Protocol): Responsible for addressing and routing data packets so 
  they can travel across networks and arrive at the correct destination. (IPv4 uses 
  32-bit addresses; IPv6 uses 128-bit addresses).
* TCP (Transmission Control Protocol): Connection-oriented protocol. It ensures reliable, 
  ordered, and error-checked delivery of packets between applications.
* UDP (User Datagram Protocol): Connectionless protocol. It prioritizes speed over 
  reliability, making it ideal for live streaming, gaming, and DNS.
* HTTP/HTTPS (Hypertext Transfer Protocol / Secure): The foundation of data exchange 
  on the World Wide Web. HTTPS includes SSL/TLS encryption for security.
* DNS (Domain Name System): The "phonebook of the Internet." It translates 
  human-readable domain names (like google.com) into machine-readable IP addresses.
* DHCP (Dynamic Host Configuration Protocol): Automatically assigns IP addresses 
  and other network configurations to devices joining a network.


6. NETWORKING HARDWARE
----------------------
* Hub: A basic device that connects multiple devices in a LAN. It transmits data 
  to all ports indiscriminately, creating unnecessary network traffic.
* Switch: A smarter device that connects devices in a LAN. Unlike a hub, a switch 
  inspects incoming frames and routes them specifically to the target device using 
  MAC addresses.
* Router: A device that forwards data packets between different networks (e.g., 
  connecting your home LAN to the Internet WAN). It operates using IP addresses.
* Modem: Short for Modulator-Demodulator. It converts digital data from a computer 
  into analog signals suitable for transmission over telephone lines or cable lines, 
  and vice versa.
* Firewall: A security device that monitors and filters incoming and outgoing network 
  traffic based on an organization's previously established security policies.


7. NETWORK SECURITY BASICS
--------------------------
Securing a network involves safeguarding infrastructure and data from unauthorized 
access, misuse, or alteration.
* Encryption: Scrambling data so that it can only be read by someone who has the 
  correct decryption key.
* Access Control: Defining which users and devices have access to specific parts 
  of a network (using passwords, multi-factor authentication, and ACLs).
* Intrusion Detection/Prevention Systems (IDS/IPS): Monitoring tools that detect 
  suspicious activities and attempt to block potential network attacks.
