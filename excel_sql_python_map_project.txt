1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This document outlines a comprehensive project mapping workflow that integrates 
Excel, SQL, and Python. The objective is to build an automated data pipeline 
that ingests raw transactional or spatial data from Excel files, stores and 
queries it efficiently using an SQL database, and leverages Python for spatial 
data processing, mapping, and interactive visualization.

2. STEP 1: EXCEL DATA STRUCTURING
--------------------------------------------------------------------------------
The raw data originates in Excel spreadsheets. Standardizing column structures,
ensuring proper data types, and verifying geographical coordinates (Latitude and 
Longitude) are required prior to ingestion.

Sample Excel Structure (Sheet Name: `Store_Locations.xlsx`):

| Store_ID | Store_Name     | Region  | Revenue_USD | Latitude  | Longitude  | Status |
|----------|----------------|---------|-------------|-----------|------------|--------|
| STR_001  | Downtown Hub   | North   | 125000.00   | 40.712776 | -74.005974 | Active |
| STR_002  | Westside Plaza | West    |  98000.50   | 34.052235 | -118.24368 | Active |
| STR_003  | Metro Center   | East    | 145000.75   | 41.878113 | -87.629799 | Active |
| STR_004  | Harbor Point   | South   |  87500.00   | 25.761680 | -80.191790 | Inactive|

Excel Checklist:
- Ensure no merged cells exist.
- Ensure Header row is strictly on Row 1.
- Confirm Latitude range: -90.0 to 90.0; Longitude range: -180.0 to 180.0.
- Save as standard `.xlsx` format.


3. STEP 2: SQL DATABASE SCHEMA & QUERIES
--------------------------------------------------------------------------------
SQL serves as the centralized, reliable data store. Below are the SQL DDL statements 
for setting up the relational schema, as well as analytics queries for filtering map data.

--- SQL DDL Schema ---

CREATE TABLE store_locations (
    store_id VARCHAR(20) PRIMARY KEY,
    store_name VARCHAR(100) NOT NULL,
    region VARCHAR(50),
    revenue_usd DECIMAL(12,2),
    latitude NUMERIC(10, 6) NOT NULL,
    longitude NUMERIC(10, 6) NOT NULL,
    status VARCHAR(20) DEFAULT 'Active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

--- Analytical SQL Queries ---

-- Query 1: Filter Active Stores with Revenue > $100,000 for Map Visualization
SELECT 
    store_id, 
    store_name, 
    region, 
    revenue_usd, 
    latitude, 
    longitude
FROM 
    store_locations
WHERE 
    status = 'Active' 
    AND revenue_usd >= 100000.00;

-- Query 2: Regional Performance Summary
SELECT 
    region,
    COUNT(store_id) AS total_stores,
    SUM(revenue_usd) AS total_revenue,
    AVG(revenue_usd) AS avg_store_revenue,
    AVG(latitude) AS center_lat,
    AVG(longitude) AS center_lon
FROM 
    store_locations
WHERE 
    status = 'Active'
GROUP BY 
    region;


4. STEP 3: PYTHON PIPELINE & INTERACTIVE MAPPING CODE
--------------------------------------------------------------------------------
The Python script executes the end-to-end workflow:
1. Reads raw data from Excel.
2. Loads data into an SQL database (SQLite example, scalable to PostgreSQL/MySQL).
3. Executes an SQL query to extract map-ready data.
4. Generates an interactive geospatial map using `folium`.

--- Python Code (`map_project_pipeline.py`) ---

```python
import sqlite3
import pandas as pd
import folium
from folium.plugins import MarkerCluster

def main():
    excel_path = "Store_Locations.xlsx"
    db_path = "project_database.db"

    # Step A: Ingest Excel Data
    print("Reading data from Excel...")
    df_excel = pd.read_excel(excel_path)

    # Step B: Store into SQL Database
    print("Writing data to SQL database...")
    conn = sqlite3.connect(db_path)
    df_excel.to_sql('store_locations', conn, if_exists='replace', index=False)

    # Step C: Execute SQL Query to Retrieve Specific Data for Mapping
    sql_query = """
        SELECT store_id, store_name, region, revenue_usd, latitude, longitude
        FROM store_locations
        WHERE status = 'Active' AND revenue_usd >= 100000.00
    """
    map_data = pd.read_sql_query(sql_query, conn)
    conn.close()

    print(f"Retrieved {len(map_data)} active records for mapping.")

    # Step D: Map Generation with Folium
    avg_lat = map_data['latitude'].mean()
    avg_lon = map_data['longitude'].mean()

    # Initialize Base Map centered on data average
    m = folium.Map(location=[avg_lat, avg_lon], zoom_start=4, tiles='OpenStreetMap')
    marker_cluster = MarkerCluster().add_to(m)

    # Add Markers to Map
    for idx, row in map_data.iterrows():
        popup_html = f"""
        <div style='font-family: Arial; font-size: 12px;'>
            <b>Store ID:</b> {row['store_id']}<br>
            <b>Name:</b> {row['store_name']}<br>
            <b>Region:</b> {row['region']}<br>
            <b>Revenue:</b> ${row['revenue_usd']:,.2f}
        </div>
        """
        folium.Marker(
            location=[row['latitude'], row['longitude']],
            popup=folium.Popup(popup_html, max_width=250),
            tooltip=row['store_name'],
            icon=folium.Icon(color='blue', icon='shopping-cart', prefix='fa')
        ).add_to(marker_cluster)

    # Export Map output
    output_html = "store_locations_map.html"
    m.save(output_html)
    print(f"Interactive map successfully generated: {output_html}")

if __name__ == "__main__":
    main()
```


5. SUMMARY & BEST PRACTICES
--------------------------------------------------------------------------------
- Data Validation: Always clean missing or malformed coordinates in Excel before
  pushing to SQL (e.g., using `df.dropna(subset=['latitude', 'longitude'])`).
- Performance: For large datasets (100k+ rows), use spatial indexing in SQL 
  (e.g., PostGIS extension in PostgreSQL) and `GeoPandas` in Python.
- Automation: Schedule the Python script using Windows Task Scheduler or Cron 
  to automatically read updated Excel sheets, sync with SQL, and refresh the map.
